設計ルール

  • サーバーは全 finding ID の提出を必須にする。未判断・改ざん ID は 400 で拒否。
  • 1件でも承認なら編集開始ボタンを表示し、編集ジョブには承認済み finding のみを渡す。
  • 全件却下なら最終公開確認状態へ遷移する。

このまま原音声を公開しますか？

公開すると、R2 への音声配置と RSS 更新ジョブを開始します。

  • 原音声の該当発話は無音化されません。
  • 公開前監査は再実行せず、今回保存した却下判断を使用します。
  • この操作後、エピソードは「処理中」になります。

確認操作は `POST /confirm-original-publish` を実行します。
